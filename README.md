# Expense Tracker App

A responsive Expense Tracker web application built using React and Tailwind CSS.
The app allows users to add, manage, categorize, and track expenses with real-time currency conversion support.

## Features

- Add new expenses
- Delete expenses
- Expense category tracking
- Total expense calculation
- Category-wise breakdown
- Live currency conversion using API
- Responsive design for desktop and mobile
- Local storage persistence
- API loading and error handling

## Tech Stack

- React
- Vite
- Tailwind CSS
- JavaScript
- Currency Converter API
